# examples — 전 과정 산출물 (합성 예제)

완성본만이 아니라 **게이트가 무엇을 잡아냈는지**가 관전 포인트다. 읽는 순서: `01`(설계/분석) → `02`(게이트1 판정) → `03`(근거) → `04`(초안) → `05`(게이트2 검수) → `06`(최종 파일).

| 폴더 | 주제(합성) | 봐야 할 것 |
|---|---|---|
| `socsci-paper-demo/` | 재택근무→조직몰입 (이론·문헌, 데이터 없음) | `02_design_gate.md` 주장범위 교정 + **분석가 자동 스킵** · `05_review.md` 유령인용 0건 검증 · `06_paper.docx` |

※ 전부 합성 주제·데모 규모다. 근거는 핵심 수치만 실검증(URL 병기)했고 미확보분은 `[보강 필요]`로 남겼다 — 이 정직성 규율 자체가 킷의 일부다.
